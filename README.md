# Kivach Association Interculturelle

Макет многостраничного сайта ассоциации. Исходный код написан на TypeScript; сборка — Vite.

## Страницы

- `/` — главная
- `/association/` — об ассоциации
- `/presidente/` — слово президента
- `/projets/` — проекты
- `/galerie/` — фотогалерея
- `/contact/` — контакты

Каждая страница имеет собственный `index.html` и открывается по прямой ссылке. Навигация и содержимое страниц находятся в `src/main.ts`, стили — в `src/style.css`. Оригинальный логотип предоставлен ассоциацией и встроен без перерисовки в `src/logo.ts`.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Проверка и сборка:

```sh
npm run typecheck
npm run build
```

Готовый сайт появится в `dist/`. Пока это макет: портрет и фотографии проектов нужно заменить реальными материалами; форма контактов не отправляет данные. Render и Supabase будут подключены отдельным этапом.
