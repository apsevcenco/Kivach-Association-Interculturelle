# Kivach Association Interculturelle

Многостраничный сайт ассоциации на TypeScript и Vite.

## Страницы

- `/` — главная
- `/association/` — об ассоциации
- `/presidente/` — слово президента
- `/projets/` — проекты
- `/galerie/` — фотогалерея
- `/contact/` — контакты
- `/admin/` — редактор сайта

Каждая страница имеет собственный `index.html` и открывается по прямой ссылке. Навигация находится в `src/main.ts`, исходные тексты страниц — в `src/templates.ts`, настройки редактора — в `src/cms.ts`, стили — в `src/style.css`. Оригинальный логотип предоставлен ассоциацией и встроен без перерисовки в `src/logo.ts`.

## Редактор сайта

Административная страница `/admin/` позволяет менять тексты и заголовки всех страниц, меню и подвал, загружать логотип и портрет, добавлять, удалять и переставлять проекты и фотографии галереи. Публичный сайт показывает исходный макет, пока в Supabase нет сохранённого содержимого.

Для включения редактора:

1. В проекте Supabase откройте **SQL Editor** и выполните [`supabase/migrations/20261015000000_site_editor.sql`](supabase/migrations/20261015000000_site_editor.sql). Миграция создаёт таблицы, публичный бакет `site-media` и правила RLS: посетители только читают опубликованное содержимое, редакторы могут изменять его и загружать изображения. Если бакет `site-media` уже существовал, проверьте, что он публичный и принимает JPEG, PNG, WebP, AVIF до 10 МБ.
2. В **Authentication → Users** создайте пользователя с электронной почтой и паролем. Затем в SQL Editor внесите его в список редакторов, подставив его адрес:

   ```sql
   insert into public.site_admins (user_id)
   select id from auth.users where email = 'admin@example.com'
   on conflict (user_id) do nothing;
   ```

   Результат `INSERT 0 0` означает, что пользователь с таким адресом не найден. Регистрацию посетителей через сайт редактор не предоставляет.
3. В Render у **Static Site → Environment** задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` из окна **Connect** проекта Supabase. Допускается прежнее название `VITE_SUPABASE_ANON_KEY`. Выберите **Save, rebuild, and deploy**. Эти две переменные попадают в код браузера; их защищают политики RLS. Пароль базы и secret/service-role key туда не добавляйте.
4. Откройте `/admin/`, войдите и сохраните первое изменение. После сохранения обновите публичную страницу.

## Языки и перевод

Публичные страницы поддерживают французский, английский, русский, немецкий, итальянский, арабский и испанский языки. Французский — основной язык на `/` и французских адресах страниц. Для других языков используются отдельные адреса: `/en/association/`, `/ru/association/` и так далее. Переключатель находится в шапке сайта и сохраняет текущую страницу при смене языка. Старые ссылки с `?lang=` автоматически ведут на чистый адрес. У каждой страницы есть canonical, hreflang; все 42 публичных адреса перечислены в `/sitemap.xml`. Для арабского включается направление письма справа налево. Если отдельный перевод поля ещё не сохранён, показывается французский текст. Русская редакционная версия уже подготовлена как отправная точка; проверьте её в админке перед автоматическим переводом.

В редакторе выберите **Русский**, исправьте исходные тексты, затем нажмите **Перевести этот раздел с русского** или **Перевести весь сайт с русского**. OpenAI подготовит французскую, английскую, немецкую, итальянскую, арабскую и испанскую версии. Проверьте каждую версию в редакторе и только после этого нажмите **Сохранить изменения**. Перевод использует платный OpenAI API и не сохраняется автоматически.

Для OpenAI нужен отдельный **Render Web Service** из этого же репозитория:

- Build Command: `npm ci && npm run build:server`
- Start Command: `npm run start:server`
- Environment: `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `OPENAI_API_KEY`, `PUBLIC_SITE_ORIGIN`; необязательно `OPENAI_MODEL`. Образец — `server.env.example`.
- `OPENAI_API_KEY` храните только в Environment веб-сервиса. Никогда не добавляйте его в `VITE_`-переменные, GitHub или браузер.
- В Environment существующего Render Static Site задайте `VITE_TRANSLATION_API_URL` равным публичному адресу нового веб-сервиса, затем пересоберите Static Site.

Веб-сервис принимает перевод только от авторизованного пользователя из `site_admins`, проверяет происхождение запроса и ограничивает размер и частоту запросов. `GET /health` возвращает состояние конфигурации без раскрытия секретов.

Для локального запуска скопируйте `.env.example` в `.env.local` и заполните значения своего проекта. Не сохраняйте `.env.local` в Git.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Проверка и сборка:

```sh
npm run typecheck
npm run build
```

Готовый сайт появится в `dist/`. Форма контактов пока демонстрационная и не отправляет сообщения; её текст редактируется в административном разделе.
